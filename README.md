# Public Data Scraper

A Python tool that collects public data from the web and exports it to a clean, formatted Excel file.

## Status

Work in progress (MVP).

## Planned MVP

- Collect data from a public source, with a pause between requests to respect the website
- Export the results to an Excel (.xlsx) file

## Tech Stack

- Python
- Requests / BeautifulSoup (web scraping)
- pandas / openpyxl (Excel export)
